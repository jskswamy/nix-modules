# Tool reference

What each tool module configures, what it installs, and what it brings with
it. Generated by evaluating the modules — see [Regenerating](#regenerating).

## Does it install the tool?

Most modules install the tool as well as configuring it. A few only write
config and expect the binary from somewhere else, either because the tool
is not distributed through nixpkgs or because it runs another way.

Every tool takes `tools.<name>.package`: set it to another package to swap
what gets installed, or to `null` to keep the config and install nothing.

**Installs the package** (23): `alacritty`, `beads`, `ccstatusline`, `context7-mcp`, `delta`, `difftastic`, `direnv`, `fabric`, `fish`, `git`, `gpg`, `herdr`, `hunk`, `lazygit`, `nvim`, `pet`, `ssh`, `starship`, `tig`, `tmux`, `tmuxp`, `vim`, `zsh`.

**Config only by default** (5): `agentgateway`, `ghostty`, `local-mcp`, `mcp-nixos`, `serena-mcp`.

Two of those are platform-dependent, and this page was generated on
`x86_64-linux`:

- `agentgateway` — upstream publishes an aarch64-darwin binary only, so it
  installs there and is config-only everywhere else.
- `ghostty` — deliberately config-only. Upstream's own flake builds the
  terminal on Linux only, and the usual macOS source is the `ghostty@tip`
  Homebrew cask. Set `package` to `pkgs.ghostty` (Linux) or
  `pkgs.ghostty-bin` (aarch64-darwin) to install it with Nix instead;
  ghostty-bin tracks stable releases, so it is a downgrade from the nightly
  cask.

## Each tool

<a id="toolsk-agentgateway"></a>

### `tools.agentgateway`

Routes Claude Code to the HTTP-native MCP servers, and registers itself as a Claude Code connector. Server definitions live in `config.yaml`, symlinked for instant edits.

- **Installs the package:** no by default — see above
- **Option:** `tools.agentgateway.port`
- **Writes:** `~/.config/agentgateway/config.yaml`

<a id="toolsk-alacritty"></a>

### `tools.alacritty`

GPU terminal emulator. Settings plus the upstream theme collection its `general.import` points at.

- **Installs the package:** yes
- **Enables:** `programs.alacritty`
- **Writes:** `~/.config/alacritty/alacritty.toml`<br>`~/.config/alacritty/themes`

<a id="toolsk-beads"></a>

### `tools.beads`

Memory system for AI coding agents (`bd`).

- **Installs the package:** yes
- **Writes:** `~/.config/bd/config.yaml`

<a id="toolsk-ccstatusline"></a>

### `tools.ccstatusline`

Status line formatter for Claude Code. `tools.ccstatusline.claude.enable` (off by default) also merges the `statusLine` entry into `~/.claude/settings.json`, which ccstatusline can otherwise only do from its interactive menu.

- **Installs the package:** yes
- **Option:** `tools.ccstatusline.claude`
- **Writes:** `~/.config/ccstatusline/settings.json`

<a id="toolsk-context7-mcp"></a>

### `tools.context7-mcp`

Context7 MCP server, run as a persistent HTTP daemon on port 8081 so agentgateway proxies to it instead of spawning a stdio subprocess per session.

- **Installs the package:** yes
- **Writes:** _none_

<a id="toolsk-delta"></a>

### `tools.delta`

Syntax-highlighting diff pager. Installs delta and configures it for git and lazygit: git's interactive diff filter and delta styling, and lazygit's diff renderer.

- **Installs the package:** yes
- **Writes:** nothing of its own; it adds lines to git's and lazygit's config

<a id="toolsk-difftastic"></a>

### `tools.difftastic`

Structural diff. Installs difftastic and adds the `dft` and `dftlog` git aliases and a `difftastic` difftool to git.

- **Installs the package:** yes
- **Writes:** nothing of its own; it adds lines to git's config

<a id="toolsk-direnv"></a>

### `tools.direnv`

Per-directory environments, with `nix-direnv`, a Claude-profile switcher and a `layout_venv` helper.

- **Installs the package:** yes
- **Enables:** `programs.direnv`
- **Writes:** `~/.config/direnv/direnv.toml`<br>`~/.config/direnv/direnvrc`<br>`~/.config/direnv/lib/hm-nix-direnv.sh`

<a id="toolsk-fabric"></a>

### `tools.fabric`

Four commit-message patterns for `fabric`, symlinked individually so fabric keeps managing the rest of its pattern directory.

- **Installs the package:** yes
- **Writes:** `~/.config/fabric/patterns/conventional_commit`<br>`~/.config/fabric/patterns/git_status_summary`<br>`~/.config/fabric/patterns/homework_commit`<br>`~/.config/fabric/patterns/semantic_commit`

<a id="toolsk-fish"></a>

### `tools.fish`

The daily-driver shell. Config lives in `conf.d/*.fish` and `functions/*.fish`, symlinked one file at a time so home-manager plugins can coexist.

- **Installs the package:** yes
- **Enables:** `programs.fish`
- **Options:** `tools.fish.env`, `tools.fish.repoContext`
- **Writes:** `~/.config/fish/config.fish`<br>`~/.local/share/fish/home-manager/generated_completions`<br>`~/.manpath`<br>`~/.config/fish/conf.d/` — 7 files<br>`~/.config/fish/functions/` — 11 files

Terminal emulator config, a generated `theme.conf` derived from `theme.variant`, and the `ghostty-terminfo` helper.

<a id="toolsk-local-mcp"></a>

### `tools.local-mcp`

1mcp, aggregating the stdio-only MCP servers that have no HTTP mode. Spawns each backend once and multiplexes sessions through it, which agentgateway cannot do. Registers itself as its own Claude Code connector.

- **Installs the package:** no by default — see above
- **Option:** `tools.local-mcp.port`
- **Writes:** _none_

## Regenerating

These tables are derived by evaluating each module on its own against a bare
home-manager configuration and subtracting an empty one, so they cannot
drift from the modules by editing prose. `docs/introspect.nix` holds that
evaluation; point its `hm` and `pkgs` flake references at the home-manager
and nixpkgs you want, then:

```
nix eval --impure --json -f docs/introspect.nix
```
