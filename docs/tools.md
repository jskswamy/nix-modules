# Tool reference

What each tool module configures, what it installs, and what it brings with
it. Generated by evaluating the modules — see [Regenerating](#regenerating).

## Does it install the tool?

Some modules enable a home-manager `programs.<x>` module, which installs the
package as well as writing its config. The rest only write config and expect
the binary to come from somewhere else — your system packages, your
`home.packages`, Homebrew. Importing one of those gives you a configured
tool that is not on `PATH` until you install it yourself.

**Installs the package** (9): `alacritty`, `direnv`, `fish`, `git`, `gpg`, `lazygit`, `starship`, `vim`, `zsh`.

**Config only, bring your own binary** (14): `beads`, `ccstatusline`, `fabric`, `ghostty`, `herdr`, `hunk`, `mcp`, `nbdime`, `nvim`, `pet`, `ssh`, `tig`, `tmux`, `tmuxp`.

## Each tool

<a id="toolsk-alacritty"></a>

### `tools.alacritty`

GPU terminal emulator. Settings plus the upstream theme collection its `general.import` points at.

- **Installs the package:** yes
- **Enables:** `programs.alacritty`
- **Writes:** `~/.config/alacritty/alacritty.toml`<br>`~/.config/alacritty/themes`

<a id="toolsk-beads"></a>

### `tools.beads`

Memory system for AI coding agents (`bd`).

- **Installs the package:** no — provide the binary yourself
- **Writes:** `~/.config/bd/config.yaml`

<a id="toolsk-ccstatusline"></a>

- **Installs the package:** no — provide the binary yourself
- **Writes:** `~/.config/ccstatusline/settings.json`

<a id="toolsk-fish"></a>

### `tools.fish`

The daily-driver shell. Config lives in `conf.d/*.fish` and `functions/*.fish`, symlinked one file at a time so home-manager plugins can coexist.

- **Installs the package:** yes
- **Enables:** `programs.fish`, `programs.starship`
- **Brings with it:** `tools.starship` — send back with `tools.starship.enable = false`
- **Option:** `tools.fish.repoContext`
- **Writes:** `~/.config/fish/config.fish`<br>`~/.config/starship.toml`<br>`~/.local/share/fish/home-manager/generated_completions`<br>`~/.manpath`<br>`~/.config/fish/conf.d/` — 8 files<br>`~/.config/fish/functions/` — 11 files

<a id="toolsk-ghostty"></a>

### `tools.ghostty`

## Regenerating

These tables are derived by evaluating each module on its own against a bare
home-manager configuration and subtracting an empty one, so they cannot
drift from the modules by editing prose. `docs/introspect.nix` holds that
evaluation; point its `hm` and `pkgs` flake references at the home-manager
and nixpkgs you want, then:

```
nix eval --impure --json -f docs/introspect.nix
```
